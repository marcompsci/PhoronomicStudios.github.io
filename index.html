02 / What I’m working towards

Software that meets people where they actually are.

I build tools that help people see and act on their own motion — their habits, goals, learning, health, and daily life.

The field

I’m a former Geek Squad Home Service Agent and Apple Product Specialist. I moved from Fresno to San Francisco to pursue a life in tech, build my own work, and create a better future for myself.

The focus

At Phoronomic Studios, I’m especially interested in AI systems that remain legible and accountable — software that explains itself instead of asking for blind trust.

The constraint

Accessibility isn’t a later release. Voice-first interaction, keyboard support, reduced motion, clear feedback, and privacy are build constraints from the start.

03 / Selected work

In active motion.

Applications, extensions, and experiments currently being built at Phoronomic Studios. Each links to its repository on GitHub.

  • 01
    ✦THE
    LIBRARY    explore / learn / return

    Omari’s Digital Library↗ on GitHub

    More than a bookshelf: an editorial, interactive personal library made to reward curiosity. Search by genre, open books for notes and context, save reader recommendations locally, and meet the animated frog and Meganeura guardian that live in the stacks.

    Web experience
  • 02
    SKATE
    CITY    ◒

    SkateCity↗ on GitHub

    An arcade street-skating game for iPhone and iPad. The plaza, skaters, textures, and character gear are generated in Swift at runtime — then brought to life with sessions, free skate, trick combos, grinds, goals, and a full create-a-skater flow.

    Swift · SceneKit
  • 03
    STREET
    Sesh    ↗

    StreetSesh↗ on GitHub

    A native iOS skate-spot app built around the energy of an actual session. Find spots, start live sessions, hunt for new terrain, join crews, earn trophies, and let the community vote on the places that are getting shut down.

    SwiftUI · MapKit
  • 04
    Echolisten
    closely

    Echo↗ on GitHub

    A voice-driven accessibility inspector that turns Safari into a more understandable place. Select any element to capture its HTML, CSS, XPath, and attributes; then ask Echo to analyze, explain, or suggest a fix — entirely on device.

    Safari extension
  • 05
    VSeeing
    the next
    step.

    Veya↗ on GitHub

    “See it clearly. Know what to do.” Veya turns a screenshot you choose to share and a spoken or typed question into a visual guide with numbered callouts and practical next steps — without background monitoring or photo-library access.

    iOS · Accessibility
  • 06
    SKY
    BRIEF    ✈

    SkyBrief↗ on GitHub

    A focused iOS project in active development, exploring a clearer, calmer way to understand the world overhead. Built for the moments when you look up and want the sky to make sense.

    iOS app
  • 07

    A local-first learning studio for people ready to build, not just watch tutorials. It pairs web, Python, cybersecurity, and AI-prompting lessons with 60 guided code and design missions — then runs learner work inside a sandboxed, disposable environment.
